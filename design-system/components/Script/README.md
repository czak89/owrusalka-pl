Pacifico is the brand script: the logo wordmark and very short hand-lettered callouts (3 to 4 words), tilted about -2 degrees. Type styles `script-callout` (38px) and `script-note` (20px) are in `tokens.json`.

**You provide** the text and the `.script` class (or `font-family: var(--font-script)` with `font-feature-settings: "ss01" 1`).

## Rules

- **Always enable `ss01`.** Pacifico's default ł/Ł draws a macron above the letter; stylistic set 1 draws the proper Polish diagonal stroke. The card shows both side by side.
- Colours: `c-coral` for ribbons above headlines, `c-sun-yellow` on dark fills, `c-deep-sea` for captions and signatures.
- Never for body copy, buttons, navigation or anything longer than a short line.
- Pacifico ships one weight (400).
