One panel that shows the spacing scale at work: an eyebrow, a headline, a paragraph and a button row.

## Rules

- Card padding: `space-5` (24px) to `space-6` (32px).
- Vertical rhythm inside a card: 8px heading to text (`space-2`), 12px between controls (`space-3`), 16px after a paragraph (`space-4`).
- Page gutters: `space-7` (48px) on desktop, `space-5` (24px) on mobile. Sections are `space-8` to `space-9` apart.
