Icons are Lucide (v0.469.0), inlined as SVG, stroke-based with rounded caps; Rusałka has no official icon system, so this is a substitution to be reviewed by the brand owner.

**You provide** an inline `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">` per icon, copied from Lucide 0.469.0 (ISC licence). The preview needs no script or network.

## Rules

- Default size 20px (24px also used), stroke 1.75px, colour is the surrounding text colour (`currentColor`).
- Tiles: `c-paper-2` with a `border`, `c-sun-yellow` for warm highlights, `c-deep-sea` with `c-paper` icons for dark.
- Preferred icons: `map-pin`, `phone`, `mail`, `calendar`, `users`, `bed`, `utensils`, `wifi`, `waves`, `sun`, `tent`, `tree-pine`, `arrow-right`.
- No emoji in copy, buttons or UI labels. An occasional bullet, en-dash or arrow reads as typography, not as an icon.
- The sun and wave from the logo can stand in for the brand where a circular avatar, favicon or map pin is needed.
