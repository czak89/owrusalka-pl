Badges are small pills that label an offer or a fact; eyebrows are tiny uppercase lead-ins above a heading.

**You provide** a short Polish label (*Nowość 2026*, *Plaża 50 m*). ALL CAPS is reserved for eyebrows (14px and under), section numbers and small UI tags; never for headlines.

## Badges

- Sun: `c-sun-yellow` fill, `on-accent` text.
- Success: `c-foam-wash` fill, a dot and `success-text` (5.46:1 light, 7.70:1 dark), for *Wolne terminy*.
- Sky: `c-sky-wash` fill, `c-deep-sea` text.
- Sand: `c-paper-3` fill, `c-deep-sea` text.
- Coral: `action` fill, `on-accent` text (5.35:1).
- Marine: `surface-strong` fill, `on-strong` text.
- Outline: transparent, 1px `border`, `c-deep-sea` text.
- Always `radius-pill`, 12px, weight 700.

## Eyebrows

Nunito 800, uppercase, wide tracking (`tracking-caps` scale), 12px, `accent-text` by default (5.07:1 on `c-paper`), `c-deep-sea` for variety or on a sand band. Never `c-coral` or `c-baltic-blue`: both are below 3:1 on `c-paper`. Start with a middle dot.

Pair a status badge with a word or dot, never colour alone.
