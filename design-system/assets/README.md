Usage notes for the images directly under `assets/`.

- `logo-rusalka-full.png`: primary horizontal lockup (sun, waves, handwritten wordmark). Use on white, `c-paper` or sand. Raster, shown through `<img>`.
- `logo-rusalka-on-dark.png`: lockup for dark grounds, white wordmark, transparent background. Derived from the primary PNG; use on `c-ink`, `c-deep-sea`, dark mode and darkened photos.
- `logo-rusalka-on-dark.jpg`: the earlier on-dark file with a fixed `c-ink` background. Superseded by the PNG, kept for reference.
- SVG versions of both lockups are the target format but are not here yet; they need the original vector artwork.
- `palette-reference.svg`: the official 9-colour palette card with hex values, names and intended use. A reference sheet; the working values are in `tokens.json`.
- `pacifico-polish-ligatures-reference.png`: reference image of the proper Polish ł/Ł in Pacifico (stylistic set 1, `ss01`).
- `notes/`: notes carried from the earlier project; they stay as they are.
